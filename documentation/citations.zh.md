# 引用与来源

使用本平台的软件流程时请引用 OpenMolSpec，并分别引用分析中使用的原始数据集和模型。仓库提供 `CITATION.cff` 软件引用文件。团队整理的专利实验谱库统一标注来源为 OpenDataLab。

| 资源 | 原始来源 |
| --- | --- |
| NMRexp | [Dataset v2](https://zenodo.org/records/17296666) |
| NMRSpec / NMRTrans | [Paper](https://arxiv.org/abs/2602.10158) |
| NMRGym | [Paper](https://arxiv.org/abs/2601.15763) |
| NMRShiftDB | [Project](https://nmrshiftdb.nmr.uni-koeln.de/) |
| NMRNet | [Implementation](https://github.com/Colin-Jay/NMRNet) |
| MassSpecGym | [Original paper](https://arxiv.org/abs/2410.23326), [v1.5 audit](https://arxiv.org/abs/2606.19624) |
| MassBank | [Data repository](https://github.com/MassBank/MassBank-data) |
| GLACIER / ICEBERG | [ms-pred](https://github.com/coleygroup/ms-pred) |
| QM9S | [Paper](https://www.nature.com/articles/s43588-023-00550-y) |
| QMe14S | [Paper](https://arxiv.org/abs/2501.18876) |
| openSpec / Vib2Mol | [Project](https://github.com/X1nyuLu/openSpec-alpha) |
| NMRInversions.jl | [Project and citation](https://github.com/aris-mav/NMRInversions.jl) |
| DeepSeek Harness | [Architecture reference](https://github.com/deepseek-ai/deepseek-harness) |

各来源保留其数据与代码使用条款。[Data](data/index.md) 列出本平台使用的准确版本、统计范围与可用性检查。
