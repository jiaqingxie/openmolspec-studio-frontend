# Publication status

The documentation is published at [Read the Docs](https://openmolspec-10.readthedocs.io/en/latest/), with a [Chinese edition](https://openmolspec-10.readthedocs.io/en/latest/zh/index.html). The site contains 150 HTML pages, including 68 executed notebook previews and their downloads. Use the language switch on each page. The first verified hosted build is [35915674](https://app.readthedocs.org/projects/openmolspec-10/builds/35915674/), from release commit `5e8ce72655105f4a6cd61859c9c98c0574d36955`.

Read the Docs builds the `release/openmolspec-v1` branch using the repository-root `.readthedocs.yaml`. Local, CI and hosted builds share `python scripts/build_readthedocs.py --output site --strict` after installing `requirements-docs.txt`. The frontend's Full documentation link uses the live URL by default; `OPENMOLSPEC_DOCS_URL` can override it. Release updates can be triggered with `python scripts/publish_readthedocs.py --apply --project openmolspec-10 --wait 600` after pushing the matching commit.
