# 账户与外部 Agent 验收

实测日期为 2026-11-03。使用 PostgreSQL 17、隔离的数据库和附件目录。
原开发实例继续使用原有端口和数据。

## 可复现步骤

1. 按 [启动说明](../README.md) 准备空 PostgreSQL 并启用开发模拟登录。
   启动完成后访问工作台和 `/integrations/mcp`。首次启动的用户、会话和计算任务表均为空。
2. 访客输入一段草稿并选择一份 CSV。切换到 MCP 指南再返回。
   使用模拟研究员登录，保存 CSV，确认草稿仍在并可预览附件。
   退出后使用模拟分析员登录，确认研究员的记录和附件不会出现。
3. 在「额度与用量」查看首次赠送。再登录同一身份，核对赠送记录只有一笔。
4. 在「访问令牌」创建一枚短期令牌。参考指南的 SDK 示例完成工具发现并检查 `CCO`，
   核对分子式为 `C2H6O` 和令牌最近使用时间。撤销令牌后，重复请求应返回 HTTP 401。
5. 在配置真实模型的环境发送「只回复 MOL-SPEC-OK，不调用任何工具」。
   核对流式回复结束、重新载入后仍能读到回复，以及模型用量出现在账户明细中。

## 实测结果

- 后端 108 项测试通过。实际 PostgreSQL 测试覆盖会话过期、生产拒绝模拟登录、令牌摘要和撤销、
  下载与 SSE 跨账号访问、计算引用隔离、同账号幂等重试、不同账号同请求号、并发扣费、
  余额不足、失败或取消释放、重启恢复和重复完成。
- 前端 34 项测试、TypeScript 类型检查和 Next.js 生产构建通过。
- 浏览器在桌面和 375px 移动视口验证公开指南、配置复制、导航、键盘操作、访客本地编辑、
  草稿和待上传文件跨登录保留、账户切换、额度面板及令牌单次显示与撤销。
- Tensoris `deepseek-v4.1-flash-1017` 完成实际浏览器对话、SSE、刷新回读和用量记录。
  本次提示词未触发工具调用。Agent 的内部 MCP 往返和谱图续用由隔离测试覆盖。
- 官方 MCP Python SDK 经公开网关实际完成初始化、工具发现和乙醇检查。
  集成测试通过同一网关提交可结算的测试计算，随后使用网页会话读取该结果和用量。
- 真实环境的谱图预测、结构检索、结构生成和能隙预测缺少对应的模型、实现或参考资产。
  使用受控科学输入及测试模型验证任务生命周期和结算。缺资产时返回能力错误并保留余额。
